2  Git 初始配置

本页介绍安装 Git 后要完成的初始配置：设置身份信息、处理换行符、接入 VS Code，并配置 SSH 连接 GitHub。这些步骤与操作系统无关，装完 Git 后都要做一遍。

2.1 设置身份信息

安装后第一件事是设置你的身份信息。Git 用它标注每一次提交，全局配置一次即可：

git config --global user.name "你的名字"
git config --global user.email "you@example.com"

注意：邮箱建议与 GitHub 账号邮箱一致，这样提交记录能正确关联到你的 GitHub 主页。

查看当前配置：

git config --global --list

配置保存在用户主目录的 .gitconfig 文件中，也可以直接编辑：

git config --global --edit

2.2 处理换行符：core.autocrlf

Windows 使用 CRLF 作为行结束符，Linux/macOS 使用 LF。跨平台协作时，换行符差异会让 diff 出现大量无意义改动。建议启用 Git 的自动转换：

git config --global core.autocrlf true

效果是：检出代码时转换为 CRLF（Windows 友好），提交时转换为 LF（仓库内统一）。仓库里永远只存 LF，不同系统各取所需。

注意：仓库内统一使用 LF 是开源项目的通行做法。不要在仓库里存储依赖 CRLF、只有 Windows 能正常处理的文件格式，否则每次提交都可能出现整行改动。

2.3 VS Code 集成

VS Code 内置了 Git 支持，左侧源代码管理面板可以查看改动、暂存、提交、推送，配合集成终端使用效率很高。

  • 打开源代码管理面板：Ctrl+Shift+G
  • 打开集成终端运行 git 命令：Ctrl+`（反引号键）

提示：VS Code 官方 Git 文档

2.4 生成 SSH 密钥并配置到 GitHub

SSH 协议让你免去每次输入用户名密码，是连接 GitHub 的推荐方式。以下命令在 Git Bash 中执行。

2.4.1 生成密钥

ssh-keygen -t ed25519 -C "you@example.com"

一路回车使用默认路径（~/.ssh/id_ed25519），也可以为密钥设置口令（passphrase）。

注意：-C 是注释，建议填你的邮箱，方便识别密钥归属。老系统若不支持 ed25519，可用 ssh-keygen -t rsa -b 4096。

2.4.2 启动 SSH 代理并添加密钥

以下命令在 Git Bash 中执行。只有给私钥设置了口令才需要这一步，没设口令可以直接跳过。

eval "$(ssh-agent -s)"  # 启动 ssh-agent，并让当前终端连上它
ssh-add ~/.ssh/id_ed25519  # 把私钥解锁并加载到代理内存（有口令则输入一次）

2.4.3 查看公钥并复制

cat ~/.ssh/id_ed25519.pub

把输出的内容完整复制（以 ssh-ed25519 开头）。

2.4.4 添加到 GitHub

  1. 登录 GitHub，打开 SSH keys 设置页
  2. 点击 New SSH key
  3. Title 随意填写（如 Windows），Key 粘贴刚才复制的公钥
  4. 点击 Add SSH key

2.4.5 验证连接

ssh -T git@github.com

首次连接会提示确认指纹，输入 yes。看到下面的输出即表示成功：

Hi <你的用户名>! You've successfully authenticated, but GitHub does not provide shell access.

2.5 小结

到这里，环境配置完成：

项目 命令/文件
Git 安装 官方安装包，git --version 验证
身份信息 git config --global user.name / user.email
换行符 git config --global core.autocrlf true
编辑器 VS Code 源代码管理面板
SSH 连接 ~/.ssh/id_ed25519，已添加到 GitHub
